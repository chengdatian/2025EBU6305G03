# Color Coding Learning Platform

A collaborative university coursework project developed by a six-member student team. The platform introduces color-coding concepts through bilingual learning content, interactive activities, self-tests, community content, and accessibility-oriented support.

## Live Demonstration

[Open the deployed project](https://chengdatian.github.io/2025EBU6305G03/)

## Core Features

- Responsive learning pages for desktop and mobile browsers
- Chinese and English content switching
- Interactive game and self-test modules
- Community and support modules
- Accessibility-oriented color presentation and sound-enhanced interactions

## Technology

HTML, CSS, JavaScript, GitHub Pages, Git, and GitHub pull-request workflows.

## Team Structure

The project was divided into six page-level modules owned by different team members. Work was integrated through GitHub branches and pull requests. Team attribution is preserved in repository history and pull-request records; student identifiers are intentionally omitted from this public summary.

## Repository Structure

- `homepage.html` — marketing homepage
- `learning.html` — learning module
- `game.html` — interactive game module
- `test.html` — self-test module
- `community.html` — community module
- `support.html` — accessibility and support module
- `css/` and stylesheet files — shared presentation

## Running Locally

Clone the repository and open `index.html` in a modern browser. No build step or external dependency is required.
